# martemagua 🌊

**mar + tem + água** — Portuguese for *"the sea has water"*. It's my nickname,
and it comes in many flavours: martemalga, martempeixe, martembolha…

This repository is building **martemagua.com**: an interactive sea on a web
page. You touch it, tilt your phone, and type words — *o mar tem ___* — and
whatever you write becomes something the sea has. The more words you
discover, the more the things in the sea play with each other.

It is also a learning project: built together with AI, understood end to end.
