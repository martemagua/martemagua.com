# Decision records

One short file per technical decision, numbered in order: `0001-…`, `0002-…`.
Each one says what we had to decide, which options we looked at, what we
picked, and what that costs us. Copy [0000-template.md](0000-template.md) to
start a new one.

Records are never rewritten. If we change our minds, a new record replaces the
old one and the old one is marked *Superseded by 00NN*. That way the history of
*why* stays readable.
